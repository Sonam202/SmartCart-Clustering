
# SmartCart Clustering

## Project Overview
SmartCart Clustering is a machine learning project that uses clustering algorithms to group customers based on their shopping behavior.

## Objective
The main objective of this project is to identify customer groups with similar purchasing patterns.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Scikit-learn
- Jupyter Notebook

## Algorithms Used
- K-Means Clustering
- Agglomerative Clustering

## Project Workflow
1. Data collection
2. Data preprocessing
3. Exploratory Data Analysis (EDA)
4. Feature scaling
5. Clustering using machine learning algorithms
6. Cluster evaluation using the Elbow Method and Silhouette Score
7. Visualization and interpretation of clusters
